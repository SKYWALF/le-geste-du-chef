# Le Geste du Chef

Première maquette fonctionnelle du site de cuisine. Les recettes affichées sont des exemples de démonstration, sans avis fictifs. L'espace administrateur et la base de données seront ajoutés ultérieurement.

Ouvrir `index.html` pour prévisualiser localement. Les images de démonstration sont des créations graphiques et ne sont pas des photographies des recettes de l'auteur.
